이 웹 앱은 서버 설치나 추가 비용 없이, GitHub Pages를 통해 100% 무료로 배포할 수 있습니다.

  1. GitHub(github.com)에서 New Repository를 생성합니다. (예: prompt-studio)
  2. 이 파일의 전체 코드를 index.html이라는 이름으로 업로드(Add file -> Create new file)합니다.
  3. 저장소 상단 Settings -> Pages 메뉴로 이동합니다.
  4. Branch를 main (또는 master)으로 선택하고 Save를 누릅니다.
  5. 약 1분 뒤 https://<내깃허브아이디>.github.io/prompt-studio 주소로 웹 앱이 전 세계에 공개됩니다!
